إدارة البيانات

الإضافة والتعديل والحذف تعمل عبر SheetDB. لا تجعل صلاحيات الكتابة عامة إلا بعد تقييد API في SheetDB.

الاستيراد والتصدير

التصدير يحفظ البيانات الحالية بصيغة CSV أو JSON. الاستيراد يضيف الصفوف إلى Google Sheet عبر SheetDB.
استيراد CSV
يفضل أن تكون أسماء الأعمدة في الصف الأول مطابقة لأسماء Google Sheet.

إعدادات الربط

هذه النسخة لا تحتاج Google Maps API Key. الخريطة تعمل بواسطة Leaflet مع OpenStreetMap.
يتم استخدام خرائط OpenStreetMap مع Leaflet. يجب إبقاء إسناد OpenStreetMap ظاهرًا على الخريطة. خادم البلاطات العام لديه سياسة استخدام عادلة، لذلك تجنب الاستخدام الكثيف أو التحميل الآلي الكبير.
